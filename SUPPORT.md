# Support

There is no supported production release yet. Planning discussions, reproducible bug reports, and narrowly scoped implementation questions may be opened as GitHub issues after the repository is published; responses are best effort.

Maintainers do not currently provide uptime guarantees, private deployment support, emergency response, model-design commissions, physical printing, IP clearance, or print-success warranties.

Security concerns should follow `SECURITY.md`. Questions containing private references, credentials, signed URLs, or personal data must not be posted publicly.
